## Python static server

If you wish to see what your website would look like if deployed 'on the web', you can make use of the python static webserver.

In a command prompt window, inside this folder, run: `python -m http.server`

```bash
$ python -m http.server
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
```

The port will be listed (in the above case, port 8000) - you can then view the webpage on http://localhost:8000 (where 8000 is the port number listed).
